## 📝 Project Description

This project implemented a **DJ machine** using the programming environment **Pure Data (PD)** and the mobile application **OSC Controller** for interaction.

We developed an OSC control interface with custom buttons and sliders to establish real-time communication with the Pure Data patch. This setup allowed us to design and manipulate audio responses, effectively creating a musical piece and simulating the functionality of a professional DJ machine through the integration of the PD environment.

---


The project was developed following core **Clean Code** principles to ensure that the source code (the Pure Data patch and its logic) is highly readable, maintainable, and easily extensible.
